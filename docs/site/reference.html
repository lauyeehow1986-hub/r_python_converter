API Reference

pyport — Converter, Parser, Transpiler, & Package Builder

Function Description
convert(source, dest, pkg_name = NULL, overwrite = TRUE) Convert a Python module, source directory, .tar.gz sdist, or .whl wheel into a standalone R CMD check-clean R package.
build_r_package(pkg_dir, dest_dir = NULL, binary = FALSE) Build a portable CRAN source tarball (.tar.gz) and optional pre-compiled platform binary (.zip on Windows, .tgz on macOS).
parse_python(source) / parse_python_file(path) Parse Python 3 source code into a py_ast_node tree using the vendored tree-sitter-python v0.23.6 C grammar.
ast_dump(node, indent = NULL) Format a py_ast_node tree in CPython 3.12 ast.dump() notation.
analyze_python(source) / analyze_escape(node) Perform lexical scope resolution (local, global, nonlocal, generators) and container escape analysis.
transpile_python(source) / eval_python(source, envir) Lower Python source code to executable R code backed by pyrt and optionally evaluate it in an environment.
convert_pytest_code(source, pkg_name = NULL) Translate Python pytest and unittest test files into testthat R expectations.
check_python_license(license_str) Audit Python license metadata and map permissive and GPL/LGPL licenses to CRAN License: strings.
detect_native_extensions(source_dir) Detect C/C++, Cython (.pyx), and Rust (Cargo.toml / PyO3) extensions in a Python package.
cpython_shim_header() / transpile_c_extension(code, pkg_name) Generate pyport_cpython_shim.h and lower C/Cython scalar functions and PyMethodDef + PyArg_ParseTuple tables to R .Call wrappers.
transpile_pyo3_rust(rust_code, pkg_name) Rewrite Rust PyO3 #[pyfunction], #[pyclass], and #[pymethods] attributes into extendr attributes and generate Makevars / Makevars.win.
